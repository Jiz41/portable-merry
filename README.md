# ポータブルメリー

馬のデータ作成を手伝うアシスタント「谷上メリー」を、どのAIにも呼び出せるようにした資料一式です。このリポジトリをAIに読ませると、メリーがやってきます。

## いちばん簡単な方法：AIに読み込み方を聞く
AIの画面や機能は、よく変わります。そこで、次の文を、使いたいAIにそのまま送ってください。そのAI自身が、自分の環境での読み込み方を案内します。読めるなら、その場で読み込みます。

> 次のGitHubリポジトリを、あなたに読み込ませて使いたいです。
> https://github.com/Jiz41/portable-merry
>
> 1. あなたはこのURLを自分で読めますか。読めるなら、README.md の「AIへの指示」に従って、そのまま始めてください。
> 2. 読めない場合は、私があなたの画面で何を操作すればよいか、番号つきの手順で教えてください。リポジトリの読み込み機能、ファイルの添付、プロジェクトやカスタム指示の置き場所のうち、あなたの環境で一番確実な方法を選んでください。ファイルが必要なら、どのファイルを、どこに入れるかを具体的に書いてください。
> 3. 知らないこと、画面の名前に自信がないことは、推測せずに「分からない」と書いてください。

読み込みが終わったら、次の一言を送ります。

> このリポジトリを読んで、README.md の「AIへの指示」に従って谷上メリーとして振る舞って。

これで解決しない場合は、下の「どのAIでも使える方法」（全部入り版を貼る）に切り替えてください。

## 使い方（人間向け）
1. GitHubのコネクタ／リポジトリ読み込み機能があるAIに、このリポジトリのURLを渡す。
2. 次の一言を送る。

> このリポジトリを読んで、README.md の「AIへの指示」に従って谷上メリーとして振る舞って。

3. コネクタが使えないAIには、`portable_ameri_all_in_one.md` を丸ごと貼る（またはファイルとして添付する）。

### AI別の読み込み方（参考・古くなっている可能性あり）
画面や機能の名前は、変わることがあります。AIに直接聞いた方が確実です（上の「いちばん簡単な方法」）。うまくいかないときは、一番下の「どのAIでも使える方法」に切り替えてください。どの手順でも、読み込ませたあとに送る一言は同じです。

> このリポジトリ（添付資料）を全部読んで、README.md の「AIへの指示」に従って谷上メリーとして振る舞って。

#### Claude（claude.ai）
1. 左のメニューの「プロジェクト」から、新しいプロジェクトを作る。
2. 「プロジェクトの知識」の「＋」→「GitHub」を選ぶ。
3. このリポジトリのURLを貼り、読み込むファイルを選ぶ（`portable_ameri_all_in_one.md` 以外の6ファイルで足りる）。
4. `ameri_boot_prompt.md` の中身を、プロジェクトの「指示」欄に貼る。
5. プロジェクトの中で新しいチャットを開き、上の一言を送る。
6. リポジトリを更新したら、「Sync」で取り込み直す。非公開リポジトリは、GitHubアプリへの許可が要る。

#### Claude Code／Codex（ターミナル）
1. `git clone` でこのリポジトリを手元に取り込み、そのフォルダで起動する。
2. 上の一言を送る（フォルダ内のファイルをAIが自分で読む）。

#### Gemini（ウェブ版・パソコン）
1. チャット欄の「＋」→「コードをインポート」を選ぶ。
2. このリポジトリのURLを入れる。
3. 上の一言を送る。
- 1つのチャットに入れられるリポジトリは1つ。スナップショットなので、更新したら入れ直す。
- URLをチャットに貼るだけでは読めない（スマホアプリで試したところ、「リポジトリの内容を読み取れなかった」と返ってきた）。スマホのアプリからは取り込めない。スマホでは、`portable_ameri_all_in_one.md` の中身を貼るのが確実。

#### ChatGPT
- **GitHubコネクタが使えるプランの場合**：設定のコネクタで GitHub を許可し、チャットでこのリポジトリを指定して、上の一言を送る。
- **コネクタが使えない、または確実に使いたい場合**：
  1. 「GPTを作成」で、新しいGPTを作る。
  2. 「知識」に `portable_ameri_all_in_one.md` をアップロードする。
  3. 「指示」欄に `ameri_boot_prompt.md` の中身を貼る。
  4. そのGPTで、上の一言を送る。
- カスタムGPTの「知識」には、リポジトリそのものを直接入れられない（フォーラム情報）。

#### Grok
1. コネクタ一覧から「GitHub」を選んで許可する（二次情報）。
2. このリポジトリを指定して、上の一言を送る。
3. できなければ、下の「どのAIでも使える方法」にする。

#### NotebookLM
1. 新しいノートブックを作る。
2. ソースの追加で「テキストをコピーして貼り付け」を選び、`portable_ameri_all_in_one.md` の中身を貼る。
3. チャットで上の一言を送る。
- リポジトリは直接読めない。

#### どのAIでも使える方法
`portable_ameri_all_in_one.md` を、チャットにそのまま貼る（またはファイルとして添付する）。そのあと、「この資料を全部読んで、谷上メリーとして振る舞って」と送る。

動作確認は、GPT（Codex経由）で2026-10-30に済ませています（`acceptance_tests.md`）。ほかのAIでの結果は、同じ表に書き足してください。

## AIへの指示
あなたがこのリポジトリを読んでいるAIなら、次の順に進めてください。

1. `ameri_boot_prompt.md` を読み、そこに書かれた約束を、あなたの指示として扱う。
2. `stat_formula_forbidden_list.md`、`tanigami_meri_profile.md`、`stat_formula_reference.md` を、この順に最後まで読む。
3. 読み終えたら、谷上メリーとして挨拶と短い自己紹介をし、算出に必要な3点（戦績表・脚質・現役か引退か）を案内する。
4. このREADMEの「使い方」「状態」は人間向けの案内なので、メリーの発言には混ぜない。

## 状態
- 算出ガイドは ver.2.0。GI勝ち馬のレーティングは、新しい式（メリー式）で算出します。
- 公式シートそのもの（全馬の一覧）は同梱していません。算出ガイドに載っているのは、シートからの一部の抜粋（実例の馬の値など）だけです。
- AIによって、口調や資料の守り方に差が出ます。完全に同じ振る舞いになる保証はありません。
- メリーの算出結果は推定値です。最終的な採否は、使う人が決めてください。
